# IP address to country database

`user-country.mmdb`, used by `Enicore\Rivena\Classes\GeoIp`: ip-location-db's country database, built from the regional
internet registries' statistics, BGP routing data and the networks' geofeeds, preferring the user's country.
https://github.com/sapics/ip-location-db, PDDL 1.0 (public domain). `bin/build.sh` downloads the latest one (updated daily).
