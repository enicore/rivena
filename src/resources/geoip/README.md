# IP address to country database

`geo-whois-asn-country.mmdb`, used by `Enicore\Rivena\Classes\GeoIp`: ip-location-db's country database, built from
the regional internet registries' and the networks' (ASN) data, so it gives the country an address is registered in.
https://github.com/sapics/ip-location-db, CC0 1.0 (public domain). `bin/build.sh` downloads the latest one (updated daily).
